# Cirrus Cloud

[Cirrus](cirrus.md) Cloud is [Nimbus Labs](nimbus-labs.md)’ commercially licensed, fully managed version of Cirrus. Launched in 2024, it runs the same engine and adds automatic scaling, backups, and usage-based pricing.

[Priya Raman](priya-raman.md), VP of Engineering since 2022, owns Cirrus Cloud reliability. Most of [Nimbus](nimbus.md) Labs’ revenue comes from Cirrus Cloud.
